# ============================================
# WHATSAPP BUSINESS API Setup Steps:
# ============================================
# 1. Create Meta Developer Account: https://developers.facebook.com/
# 2. Create a new Business App
# 3. Add WhatsApp product to your app
# 4. Complete business verification (required by Meta)
# 5. Get Phone Number ID from WhatsApp → API Setup
# 6. Generate Access Token (permanent token recommended)
# 7. Add credentials to .env.local:
#    - WHATSAPP_PHONE_NUMBER_ID
#    - WHATSAPP_ACCESS_TOKEN
# 8. Restart dev server: npm run dev
# 9. Test WhatsApp sending from SMS Admin Dashboard
#
# Benefits:
# - Messages sent directly via API (like Amazon)
# - No need to open WhatsApp manually
# - Delivery status tracking
# - Professional business messaging
# - Supports templates, media, and more
#
# Fallback:
# - If WhatsApp Business API is not configured, system automatically uses WhatsApp Web links
# - Messages will open in WhatsApp Web/App with pre-filled message

# ============================================
# FAST2SMS Webhook Setup (Optional):
# ============================================
# For delivery status and incoming SMS:
# 1. Deploy your application to a public URL (e.g., Vercel, Railway)
# 2. Go to Fast2SMS Dashboard → Settings → Webhooks
# 3. Add webhook URL: https://yourdomain.com/api/sms-webhook
# 4. Fast2SMS will send delivery status and incoming messages to your webhook
